# Tonari 界面角色矩阵 · v3.6.0

## 模式与状态

- 联机角色为 1 号基准机或 2～4 号接入机。房间信息、机号、导入与补丁选项的改动通过“保存房间设置”应用。
- 首页“游玩模式”滑杆关闭为单机、开启为联机。切换时立即保存 segatools.ini 与机器状态，使用已保存的房间和机号；其他草稿保持待保存。
- 单机或 1 号使用基准机状态，2～4 号使用接入机状态。模式卡的状态行实时显示读取结果、更新进度、保存完成、失败或缺少的前置条件。
- 网络管理员负责 ZeroTier 授权与地址分配，网络管理入口仅对联机基准机显示。
- 页面固定为“联机概览／房间设置／游戏设置／帮助与诊断”。窗口底部保留“启动游戏”；有未保存改动时，在“导入房间”右侧显示“保存房间设置”。
- “游戏设置”提供 bin 文件夹选择与常驻“刷新状态”。选择、刷新和重试均只读检测 segatools.ini、start.bat 与机器状态，三项结果分别显示。
- 启动前完成配置保存或模式切换。启动按钮不保存房间或补丁草稿。

## 流程与文案

1. “房间设置”填写或导入房间，选择本机机号，点击“保存房间设置”保存网络和机号。
2. “游戏设置”选择 bin 文件夹，查看 INI、BAT 与机器状态三项读取状态，选择可用补丁，再到首页切至联机。
3. 退出游戏，在“房间设置”点击“保存房间设置”，等待配置和机器状态应用完成。
4. 联机时在“帮助与诊断”配置防火墙，在“联机概览”检测网络；从窗口底部启动游戏。

日常切换模式时退出游戏，在首页切换单机或联机，等待状态行显示保存完成。切换使用已保存的房间，不提交机号、导入内容或补丁草稿。缺少目录或已保存房间时，按状态行提示补全。

“刷新状态”可随时重新读取所选目录，读取失败时也可点击“重试读取”。房间、机号、目录或补丁有改动时，通过“保存房间设置”应用。游戏中的机台组与营业时间仍在 TEST 中设置。

补丁卡点文案统一为：

- 修正连接等待：接入机卡在「Aグループ基準機から設定を取得します」时，基准机和接入机都要启用。
- 配信启动修复：「配信サーバーを探しています」。
